A personal habit tracker.
Users can create habits with a name and a target frequency (daily, or N times per week).
Users can check in a habit for a given date (default today) and undo a check-in.
The system shows the current streak and best streak for each habit,
and the completion rate over the last 7 and 30 days.
The system shows a simple weekly overview of which habits were done on which days.
Habit names must be unique and non-empty; check-ins in the future are not allowed.
